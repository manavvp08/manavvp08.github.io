# Manav Purswani — Product Portfolio

An original Product Analyst portfolio built from scratch with Next.js, React, TypeScript, and CSS.

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run lint
npm run build
```

Portfolio content lives in `src/data/portfolio.mjs`. The first version uses only verified résumé details and public projects from Manav's GitHub profile.
