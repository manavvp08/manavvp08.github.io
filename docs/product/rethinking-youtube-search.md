# Rethinking YouTube Search — product brief

- **Audience:** Product recruiters and hiring managers evaluating Manav's product judgement, analytical depth, and communication.
- **Problem:** The portfolio has strong delivery evidence but only one case study; it needs a clearly labelled product teardown that demonstrates discovery, scoping, trade-offs, metrics, and experimentation.
- **Why now:** The case-study navigation and evidence labels already exist, so a second study can prove range without changing the site's information architecture.
- **10-star version:** Original interviews, a labelled query-relevance dataset, an interactive prototype, and an A/B test with production traffic.
- **MVP:** An original, source-backed concept study of intent-aware YouTube Search using public product behaviour, official documentation, and six decision artifacts that make the current state, target experience, and system trade-offs scannable.
- **Anti-goals:** Copying another portfolio's wording or assets, claiming access to YouTube's internal systems, inventing measured outcomes, or redesigning the entire search and recommendation ecosystem.
- **Success:** A recruiter can quickly find the problem, JTBD, scope, strategy, trade-offs, architecture, success metrics, guardrails, roadmap, and learnings while still distinguishing facts, hypotheses, and unshipped targets; the study remains readable on desktop and mobile and exports correctly to GitHub Pages.
- **Main risks:** Overstating research, presenting architecture guesses as facts, or optimizing for technical novelty instead of a clear user problem.
- **Recommendation:** Build, provided the page is labelled as an independent concept and keeps proposed targets separate from observed results.
